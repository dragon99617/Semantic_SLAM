# 语义评测口径与当前状态

更新：2026-10-24。本文记录当前评测安排，不改写已冻结的运行和历史验收结果。

## OVO 原版评测

OVO 使用已有三维语义真值的 Replica（标准 8 场景、51 类）和 ScanNet（20/200 类）评测。建图输出三维区域及语言视觉描述符，评测时以数据集类别名称查询，按最高相似度赋类，将预测关联到真值网格顶点后比较语义标签。主要指标为 mIoU、mAcc，ScanNet 另报告频率加权版本；原论文的主评测不是实例 mAP。

固定评测类别不限制系统本身的开放词汇查询能力。原论文还展示通用自然语言查询；类别评分与自由描述查询的结论应分别说明。

来源：[OVO 原论文第 IV 节及附录 B](https://tberriel.github.io/ovo/static/pdf/ovo_final.pdf)、[官方评测入口](https://github.com/tberriel/OVO/blob/main/run_eval.py)。本地对应 `third_party/OVO/run_eval.py` 和 `ovo/utils/eval_utils.py`，项目适配入口为 `scripts/evaluate_semantic_benchmark.py`。

## 已完成工作

- 第一阶段：Replica/OSMa 共 18 组独立 OVO 基线及审计。已运行子集不等于完整官方数据集。
- 第二阶段：FAST-LIVO2 → OVO 离线接口，两种相机短段检查和 Oxford Christ Church 02/05 完整序列工程验收。
- Oxford：13 个转场窗口、114 张唯一抽样图像的标注清单，以及遵守采样时刻的预测快照。完整图像包、描述符和地图留在本机。
- 用户提供的三张 CVAT 试标及检查报告已保存；尚未作为正式真值导入，也没有计算正式语义精度。

## 后续对比安排

1. 使用已有真值的 Replica/ScanNet，对原版 OVO、本项目方法及其他方法采用统一评测。只有准备并运行对应数据之后才能报告新结果。
2. Oxford 保留为室内外转场专项评测。需要可信参考标注支持语义精度结论，可由模型预标注后人工核验，不要求从零逐像素手画。
3. 实例评测可增加 Mask mAP@[0.50:0.95]、AP50/AP75、Recall。当前二维图像标注只支持二维投影评测，不能称为三维实例 mAP。
4. 参评模型使用同一图像/真值、类别或文本查询、可见区域和评测代码。在线对比统一每个时刻可用的输入；最终地图评分另行报告。
5. 实例 mAP 不要求补全所有背景像素，但参评图片中所评类别的实例应标全；部分标注需显式限制评分范围。独立实例与成组目标的定义要预先统一。

全部未经核验的自动标注只能作为伪标注参考，所得分数反映与该参考的一致性，不能直接替代真实精度。不能直接以参评基座的预测作为真值，再据此判定模型优劣。

## 现有工具的边界

`prepare_oxford_transition_annotations.py` 和 `score_oxford_transition_annotations.py` 已实现的工具采用固定 15 类、二维像素混淆矩阵与 IoU；这是辅助评测协议，不能当作完整开放词汇评测。`test1` 的 XML 尚未自动转为正式标签。

自由文本区域评测、实例 mAP 转换与计分，以及新增模型对比仍待实现与运行。Oxford 的 `semantic_accuracy_accepted` 继续为 `false`；工程验收通过不等于语义精度验收通过。
