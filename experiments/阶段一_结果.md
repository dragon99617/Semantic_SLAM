## 关键修复与版本

- 使用有效 ROS 节点构造 ImageTransport，修复启动空指针。
- 统一 Vikit 的 ament 构建、库导出和 Sophus 1.22.10 接口，移除硬编码链接路径。
- 为 raw Image 数据关闭不需要的压缩图像解码节点。
- 删除 x86 `-march=native`：该选项导致 Eigen 使用 32 字节分配 ABI，与 Ubuntu PCL 的 16 字节 ABI 不一致，在释放点云时崩溃。GDB 和最小 PCL 测试确认根因，修复后短片段及完整序列均正常退出。
- 参数快照使用 `--no-daemon`，避免频繁启停节点后 CLI daemon 的发现缓存造成启动检查失败。

版本、补丁与排查证据：[`source_versions.json`](source_versions.json)、[`system_versions.txt`](system_versions.txt)、[`local_patches.json`](local_patches.json)、[`patches/`](patches/)、[完整复现记录](FAST-LIVO2_复现记录.md)。

- 原作者 README 中的数据入口返回 404，本次使用社区转换镜像，原始镜像与下载校验值、来源信息均已保留。尚未与原作者 ROS 1 文件的上游哈希逐一匹配。
