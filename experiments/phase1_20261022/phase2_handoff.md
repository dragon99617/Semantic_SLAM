# 第二阶段接口交接

目标是连接已有 FAST-LIVO2 与 OVO，并测量估计几何对语义地图的影响。第一阶段未实现此连接。当前原方法对比入口为 `results.json` 中的有效运行及冻结配置；旧版历史运行不能直接代替同版本对照。

| 数据/输出 | 当前契约 | 接入时需要落实 |
|---|---|---|
| 原始图像 | FPV2 为 1024×768 BGR8；Oxford 为显式缩到 720×540 的 BGR8 鱼眼图像 | OVO 使用原始输入图像，并在适配器明确 BGR8→RGB 转换；跟踪可视化 `/rgb_img` 含叠画且仍使用节点时间，不适合作为语义 RGB |
| 位姿 | `/aft_mapped_to_init` 与原生 TUM 均为世界系下 IMU 位姿，时间来自 `last_lio_update_time` | 原生输出在 LIO 更新之后、同帧 VIO 更新之前；选择并固定这一阶段，避免离线基线与在线接口混用 |
| 点云 | `/cloud_registered` 为估计世界系下注册输出，header 已改为状态传感器时刻 | 区分 LIO/VIO 两次发布及其状态，按图像时刻同步；不把输出流简单当作带独立真值的稠密深度 |
| 图像时移 | FPV2：IMU 时钟 = 相机 header −0.0136182168 s；Oxford 固定 0 | 时间戳使用整数纳秒，固定标定时移，不用测试 GT 搜索偏移 |
| 空间变换 | 每数据集 `extrin_calib.Rcl/Pcl` 为 cam←LiDAR，`extrinsic_R/T` 为 IMU←LiDAR | 推导并保存 cam←IMU；以世界 IMU 位姿组合出世界相机位姿，明确 OVO c2w 的 RDF 约定 |
| 深度 | 原 OVO 输入为 RGB-D；真实 LVI 包没有与其等价的完整 RGB-D 深度 | 投影去畸变点云，处理可见性/遮挡、无效像素、稀疏度、有效深度单位与掩膜；首版优先保留稀疏有效深度，不虚构稠密真值 |
| 相机模型 | FPV2 为带畸变 pinhole，Oxford 为 Equidistant fisheye | 原 OVO 的 pinhole RGB-D 反投影需与 RGB/深度统一：固定去畸变与新 K，或明确扩展射线模型；不能直接用鱼眼像素套 pinhole K |
| 参考数据 | Oxford 有真实 6DoF base GT；NTU/FPV2 GT 主要为棱镜位置，四元数为占位 | Oxford 可做参考位姿/估计位姿配对；NTU/FPV2 不凭位置 GT 构造完整相机姿态真值 |
| 语义/实例 GT | Replica/OSMa 可计已有语义指标；当前真实转场包没有已核验的逐点语义/对象 ID 标注 | 真实转场先做建图、覆盖与固定对象小样本检查；新语义精度或 ID 保持结论需要补标注 |

先用一个短段验证同步、坐标变换、投影与地图尺度，再对冻结序列完整运行。每个实验保存输入图像 ID、位姿/点云对应时刻、有效深度比例、处理/丢弃计数、模型版本及资源参数。以同一语义配置分别输入可用的参考几何和估计几何，才能分开评估几何误差与语义融合误差。

第一版连接应继续使用已固定的原 OVO 模型与融合设置。新增门控、撤销、恢复或复核机制及正式 LIO/LIVO 对照属于后续研究/消融，届时复制本批次的冻结基线并固定相同数据与资源预算。
